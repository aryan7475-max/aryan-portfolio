# Aryan Kumar's portfolio

A lightweight, responsive portfolio built with HTML, CSS, and vanilla JavaScript. It features layered glass surfaces, a 3D liquid button, scroll reveals, parallax, and pointer-responsive interactions. Motion is reduced for visitors who request it.

## Run locally

Open `index.html` in a browser, or serve the directory with:

```sh
python3 -m http.server 8000
```

## Make it yours

Edit `index.html` to update the introduction, toolkit, project cards, and GitHub link. The project cards feature Aryan’s real-time car tracking and driver safety management project and real-time camera tracking project. Add project links and technical details when available. Colors, layout, and glass effects live in `style.css`; interactions live in `script.js`.
